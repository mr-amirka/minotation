# minotation-docs

Справочный сайт по хендлерам `minotation` — по образцу `old/mn-docs` (1.x),
но на текущей технологической базе (v1-порт ядра, `minotation-vite`).

```bash
npm run dev    # dev-сервер
npm run build  # прод-сборка → dist/
```

## Отличия от старой версии (`old/mn-docs`)

- **Технологическая база обновлена**: `minotationProvider`/`presets` из текущего
  `minotation` (не 1.x `minimalist-notation`), сборка через `minotation-vite`
  (не webpack), React 18 без runtime-патча `React.createElement` — обычный
  `className`.
- **Визуально близко к оригиналу**: тот же тёмный интерфейс, MUI `Tabs`/`TextField`,
  подсветка совпавшего текста при поиске. Ace-редактор (тяжёлая зависимость,
  к тому же не нужна для read-only кода) заменён на `prism-react-renderer`.
- **Контент — не построчный порт старого `essences/index.js`** (1012 строк,
  ~150 хендлеров 1.x с ручными regex-описаниями). Источник здесь —
  [`HANDLERS.md`](../core/HANDLERS.md) — уже сверенный с текущим кодом
  справочник; `src/essences.ts` структурирует его в карточки. Хендлеры,
  изменившиеся или упразднённые при миграции на v1 (`fx`/`fxw`, `contrast`
  и т.п.), отражены как есть сейчас, не как было в 1.x.
- **CSS в примерах — не текст, а реальная компиляция** в браузере при старте
  приложения (`src/data.ts`, `minotationProvider` + текущий набор пресетов) —
  как и в старом `data.js`, просто на актуальном ядре.
- **Без вложенных табов "Attrs:"** — старая версия показывала один и тот же
  пример для нескольких атрибутов (`class`/`m`/`m-n`/`id`, наследие 1.x
  runtime-конвенций). Сейчас — один атрибут (`class`), одна вкладка на пример.
